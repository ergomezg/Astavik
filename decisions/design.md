# Guía y Decisiones del Sistema de Diseño Astāvik

> [!NOTE]
> Este archivo resume el sistema de diseño oficial de Astāvik Performance Lab. Para el esquema de variables completo, consultar [DESIGN.md](file:///d:/DOCUMENTOS/BIKE%20WEB_APP/astavik/DESIGN.md).

## Identidad Visual y Filosofía
- **Filosofía:** *"Velocity and Precision"* — Elite o Nada.
- **Atmósfera:** Oscura (*Void Black*), contraste técnico brutalista, densidad de datos limpia.

## Paleta de Colores Principal
- **Background / Void Black:** `#0a0a0a` / `#141313`
- **Surface Containers:** `#1c1b1b` / `#201f1f` / `#2b2a2a`
- **On-Surface (Texto Principal):** `#e5e2e1`
- **Brand / Accent Orange:** `#FF4D00` (Vibrant Orange) / `#f97316` / `#F45800`
- **Outline / Variant:** `#8e9192` / `#444748`

## Tipografía
- **Titulares & Data Display:** `Montserrat` (Pesos 700, 800, 900 / Uppercase / Letter-spacing ajustado).
- **Cuerpo de Texto & Labels:** `Inter` / `Outfit` (Pesos 400, 700).

## Componentes Clave
- Grillas brutalistas con bordes oscuros `#333`.
- Selector antropométrico interactivo para recomendaciones de talla de bicicleta.
- Badges de especificación técnica (`AERO`, `PRO`, `CHRONO`, `ESSENTIAL`).
